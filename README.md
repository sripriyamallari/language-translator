# 🌐 Language Translator

A simple and user-friendly multilingual language translation web application that helps users translate text from one language to another.

## 📌 Project Overview

Language Translator is a web-based application designed to make communication between different languages easier. Users can enter text, select the source and target languages, and get the translated text quickly.

## ✨ Features

- 🌍 Multilingual text translation
- 🔄 Source and target language selection
- 📝 Simple and clean interface
- 📋 Copy translated text
- 🔊 Listen to translated text
- 💡 Suggested phrases for quick translation
- 📱 Responsive design for different devices

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Translation API
- Replit

## 🚀 How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click **Translate Phrase**.
5. View the translated result.
6. Copy or listen to the translation.

## 🎯 Objective

The main objective of this project is to provide an easy-to-use platform for understanding and communicating across different languages.
